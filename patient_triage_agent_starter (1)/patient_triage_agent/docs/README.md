# Add public medical references here

Put public, non-patient-specific reference documents in this folder:
- official medicine patient information leaflets (PDF or TXT)
- public health symptom guidance from WHO, CDC, NHS, or your national health authority
- documents you are permitted to download and use

Do not put real patient records, names, medical histories, prescriptions, or other personal health data here.

The app indexes PDF and TXT files in this folder on startup. If this folder has no documents, retrieval returns a notice and the app should not pretend it has verified a medical source.
